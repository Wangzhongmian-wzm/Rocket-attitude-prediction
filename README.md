# 漂移距离预测模型

用 `楼层抛伞记录.xlsx` 中的实测数据训练的漂移距离预测模型。

## 仓库说明

- 本仓库同步自本地项目 `10.20漂移距离预测`。
- 原始实验视频 `10月19日.mp4`（约 404 MB）超过 GitHub 单文件 100 MB 限制，未纳入仓库；如需视频请单独存放或使用 Git LFS。
- 网页训练模式生成的 `drift_model_trained.json` 是本地生成文件，默认不纳入仓库。

## 网页版（推荐给不懂代码的使用者）

**直接双击打开 `漂移距离预测.html`**（或 `index.html`），不需要安装任何软件，也不需要联网。

网页里可以：

- **直接键盘输入**释放高度和风速（没有滑块、没有 20 m / 5 m/s 的硬限制）；
- 看到大数字（预计漂移距离）和 95% 范围；
- 看到俯视落点示意图、风速趋势图、高度趋势图；图表和区间会随输入值自动扩展；
- 超出实测范围时自动显示橙色/黄色提示；
- 点“看数字表”查看精确数字。

## 训练模式（训练后自动固化）

点右上角的 **“训练模式”**，填入你实际测到的 **高度、风速、漂移距离**，再点“添加这条数据”。模型会在原模型基础上做现场校准：

- 估计三个修正量：整体偏移、随高度变化的趋势、随风速变化的趋势；
- 样本少时只微调，样本多时才明显改变；异常点会被稳健拟合降权；
- 左侧显示 **新增样本留一误差**、校准可信度、当前修正量和不确定度；
- **每次添加/删除数据后自动固化到本机浏览器**；下次打开直接使用固化后的模型；
- 可以删除单条数据、恢复原始模型、导出校准数据 CSV；
- 点 **“下载固化模型 JSON”** 可得到 `drift_model_trained.json`，Python 可直接读取。

训练数据只保存在本机浏览器，不会上传。建议同一装置/同一场地至少加入 **3–5 条不同条件** 的数据；如果混入不同装置的数据，模型会变成折中，原 25 点误差可能变大，这是正常的。

## 命令行使用

```bash
# 基础模型：释放高度 10 m，风速 2.0 m/s
python predict.py --height 10 --wind 2.0

# 使用网页固化的模型（先在网页里点“下载固化模型 JSON”）
python predict.py --model drift_model_trained.json --height 10 --wind 2.0

# 批量预测（CSV 需要“释放高度(m)”“风速(m/s)”两列）
python predict.py --batch 待预测.csv --output 批量结果.csv

# 重新训练 / 重新画图 / 重新生成网页
python train_model.py
python make_figures.py
python build_web.py
```

## 模型

```
d(h,v) = 0.275145 · h^0.973229 · v + 0.208741 · h^0.529831
```

- `h`：释放高度（m）
- `v`：风速（m/s）
- `d`：漂移距离（m）
- 辅助输出：留空时间 `t(h) = 0.993380 · h^0.578435`（s）

## 验证结果

| 指标 | 数值 |
|---|---:|
| 训练样本 | 11.5 m 的 25 个实测点 + 1.55 m 回归锚点 |
| 11.5 m 拟合 R² | 0.917 |
| 留一法 R² | 0.898 |
| 留一法 RMSE | 1.11 m |
| 95% 预测区间覆盖率 | 96% |

## 适用范围

- 推荐：高度 **1.55–11.5 m**，风速 **0.2–3.3 m/s**。
- 7.5 / 9.5 m 属于高度内插（这两个高度本身没有实测数据）。
- 13.5 / 15.5 m 属于高度外推，误差会明显增大。
- 超出 0.2–3.3 m/s 的风速属于风速外推。

## 重要提醒

表内**只有 1.55 m 和 11.5 m 两个高度有真实数据**，且两者不是同一装置（课内风扇 vs 室外抛伞）。7.5 / 13.5 / 15.5 m 是旧模型的推算值，9.5 m 来源未标注，均未参与训练。因此：

- 本模型适合课堂演示、方案对比和量级判断；
- 不适合精确落点控制或安全边界判定；
- 13.5 / 15.5 m 的预测只能作参考，不能宣称“实测精度”。

详细的数据核查、验证指标和勘误建议见 **`模型报告.md`**。
